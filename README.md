# internship-placement-managment - Student Internship & Placement Management System

A web application that helps students discover internships, apply for opportunities and track their applications.

## Technologies Used
- HTML
- CSS
- JavaScript
- LocalStorage

## Features
- Student Login
- Internship Search
- Internship Filtering
- Apply for Internship
- Application Tracking
- Dashboard Statistics
- Responsive Design

## Future Scope
- React.js
- Node.js
- MongoDB
- Real Authentication
